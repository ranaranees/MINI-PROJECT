# MINI-PROJECT
Sales Data Cleaning Project

Overview

Cleaned and prepared a sales dataset using Microsoft Excel and Power Query for further analysis.

Transformations Performed

* Removed the unnecessary index column.
* Separated Order Date and Order Time.
* Applied Proper Case formatting to text fields.
* Changed Sales and Price Each to Currency data types.
* Removed the redundant Month column, as all visible records contained December (12).

Tools Used

* Microsoft Excel
* Power Query

Next Steps

Validate data quality and analyse sales by product, city, date, and hour.
